## 3. Service

28〜35歳前後の働く女性を対象とする、1対1のパーソナルスタイリングサービスです。

骨格診断やパーソナルカラーなど一つの診断結果だけで服を決めず、以下を総合的に整理します。

- 好み / 似合う
- 仕事 / 休日 / 暮らし
- 手持ち服 / 予算
- よく利用するブランド
- 服選びの悩み

提供価値は服を販売することや正解を押しつけることではなく、今後自分で選ぶための「服選びの軸」をつくることです。

---

## 4. Target

### メインターゲット

**28〜35歳前後の働く女性**

仕事と私生活がある程度落ち着く一方、20代前半までの感覚で選んでいた服が少しずつしっくりこなくなっています。ファッションへの関心はあるものの、情報が多く、自分なりの判断軸を持てていない状態です。

### 表面的な悩み

- 服はあるのに着たい服がない
- 朝、何を着るか迷う
- 買ったのに着ない服が増えている
- SNSで見た服が自分に似合うか分からない
- 仕事服が無難になりすぎる
- 休日服との切り替えが難しい
- 昔似合っていた服がしっくりこない
- 骨格診断やパーソナルカラーを服選びへ落とし込めない

### 深層課題

**「自分に似合う・自分らしい」を判断する軸が整理されていない。**

服の量そのものではなく、自分の場合に何を基準に選ぶかが整理されていないことが本質的な課題です。

### 情報を集めても解決しにくい理由

- 情報は得られても「自分の場合どうするか」へ変換できていない
- 診断結果を仕事・休日・手持ち服・暮らしへ落とし込めない
- 素敵に見える服と、実際に使える服の判断が結びついていない
- 情報が増えるほど選択肢が増え、自分の優先基準が曖昧になる

### 求める変化

- 朝の服選びに迷いにくくなる
- 買って後悔しにくくなる
- 自信を持って服を選べる
- 無理に流行を追わなくなる
- 仕事でも休日でも自分らしくいられる
- 年齢を重ねても服を楽しめる

### サービス利用への不安

確定済みのサービス設計では、次の不安に答えます。

- 正解や似合わない服を一方的に決められないか
- 商品購入を求められないか
- 自分の好みや生活も尊重されるか
- どのような人が担当するか
- 対面以外でも相談できるか

### CV直前の不安

料金、所要時間、対応形式、当日の流れ、持参物、決済方法、受け取れる成果が判断材料になります。確定済み情報はFIRST STYLING SESSIONとMY STYLE NOTEで明示します。

## 7. MY STYLE NOTE

初回体験後に渡す、選択肢を狭めるのではなく選びやすくするためのフィードバック資料です。

1. **MY BASE** — 取り入れやすい基本スタイル
2. **SILHOUETTE** — 選びやすいシルエット
3. **COLOR** — 手持ち服と合わせやすい色の考え方
4. **MY RULE** — 服を買う前に確認したいポイント
5. **NEXT ITEM** — 次に買い足すなら候補になるもの

「似合わない服」の禁止リストにはしません。
