# YORI VISUAL PRODUCTION HANDOFF

## 0. このファイルの役割

このファイルは、Webデザインのポートフォリオ用に自主制作する架空LP
**「yori PERSONAL STYLING」**
の正式ビジュアル素材を、別チャットで一貫して制作するための引き継ぎ資料です。

別チャットでは、このファイルを **yoriの正式ビジュアル制作ルールの正本** として扱ってください。

今回の制作全体では別途 `LP_PROJECT_BASE_SKILL.md` をベースルールとして使用しています。
そのルールに従い、正式素材は原則として、

**1種類制作 → ユーザー確認 → 修正 → 正式採用 → 次の素材**

の順で進めてください。

一度にすべての素材を生成しないでください。
未確定事項をAI側で勝手に確定しないでください。

# 2. 商材・サービス

yoriは、28〜35歳前後の働く女性を対象とした、
**1対1のパーソナルスタイリングサービス**です。

## 中心となる提供価値

**服選びの答えを渡すのではなく、今後自分でも選べる「服選びの軸」を一緒につくる。**

以下を総合して整理します。

# 3. ターゲット

## メインターゲット

**28〜35歳前後の働く女性**

仕事と私生活がある程度落ち着いてきた一方で、
20代前半までの感覚で選んでいた服が少しずつしっくりこなくなっている。

ファッション自体には関心があるものの、
情報が多すぎて自分なりの判断基準を持てていない。

## 表面的な悩み

- 服はあるのに着たい服がない
- 朝に何を着るか迷う
- 買ったのに着ない服が増えている
- SNSで見た服が自分に似合うか分からない
- 仕事服が無難になりすぎる
- 休日服との切り替えが難しい
- 昔似合っていた服がしっくりこない
- 骨格診断やパーソナルカラーを服選びへ落とし込めない

## 深層課題

**自分に似合う・自分らしいを判断する軸が整理されていない。**

本人は「服が足りない」と感じることがありますが、
本当の課題は服の量ではありません。

## 本人が求める変化

- 朝の服選びに迷いにくくなる
- 買って後悔しにくくなる
- 無理に流行を追わなくなる
- 自信を持って服を選べる
- 仕事でも休日でも自分らしくいられる
- 年齢を重ねても服を楽しめる

# 7. MY STYLE NOTE

初回体験後に利用者へ渡す、yori独自のフィードバック。

以下の5項目を想定します。

1. **MY BASE**  
   自分が取り入れやすい基本スタイル

2. **SILHOUETTE**  
   選びやすいシルエット

3. **COLOR**  
   手持ち服と合わせやすい色の考え方

4. **MY RULE**  
   服を買う前に確認したいポイント

5. **NEXT ITEM**  
   次に買い足すなら候補になるもの

禁止リストを作るものにはしません。

「この服は似合わない」ではなく、
**選択肢を狭めるのではなく、選びやすくする**ことを重視します。

# 13. 服選びタイプ診断

質問数は5問程度を想定。

候補：

1. 朝、服を選ぶとき
2. 服を買うとき
3. SNSや雑誌を見たあと
4. クローゼットを見たとき
5. 今一番変えたいこと

## 診断タイプ

### TYPE 01
**情報を集めすぎタイプ**

情報は持っているが、
「自分の場合どうするか」が整理できていない。

### TYPE 02
**いつもの服に戻るタイプ**

失敗したくないため、
安心できる服へ戻りやすい。

### TYPE 03
**買ってから迷うタイプ**

素敵と思って購入しても、
手持ち服・生活・組み合わせまで考えきれず使いにくくなる。

### TYPE 04
**無難に整えすぎタイプ**

使いやすい服を選べているが、
「嫌いではないけれど好きでもない」という状態になりやすい。

## 診断表現のルール

性格・体型・似合う服を断定する診断にはしません。

結果には、

**「今のあなたには、こんな傾向があるかもしれません。」**

程度の柔らかな表現を使用。

また、

**タイプに優劣はなく、服選びの迷い方を整理するための簡易チェック**

であることを明記します。

# 23. Photography Rule

## Light

柔らかな自然光。

**午前9時〜午後2時程度**

## Saturation

## Texture

「綺麗だが完璧ではない」。

# 35. 素材制作時の最重要優先順位

1. 人物の同一性
2. 同一ブランドに見えること
3. 光・色温度の統一
4. 衣装テイストの統一
5. スタジオの統一
6. 写真のリアリティ
7. 各素材の役割が重複していないこと
8. LPへ配置したときの文字スペース
9. SP / PCでトリミング可能な構図
10. AI感を抑えること

---

# 36. 画像内テキストのルール

原則として、
正式写真にコピー・見出し・ロゴ等の文字を焼き込まない。

文字はHTML / CSSで実装する。

理由：

- Responsive対応
- Accessibility
- 修正容易性
- SEO
- 画質
- SP / PCでのレイアウト変更

のため。

MY STYLE NOTEなど、紙そのものを写真に写す場合も、
読ませる長文は生成画像へ含めず、
実装側で補完すること。

# 38. 別チャットで最初に行うこと

このファイルを添付した別チャットでは、
まず内容を読み、正本ルールとして認識してください。

その後、

**PHASE 01 / Hero Main Photo 1点のみ**

の制作から開始してください。

Hero採用前に、

- Stylist
- Simulation
- Styling Examples
- Final CTA

などへ進まないでください。

画像生成後はユーザーが確認し、
修正または正式採用を判断します。

# 39. 現段階でまだ行わないこと

別チャットの素材制作開始時点では、
以下を勝手に進めない。

- HTML実装
- CSS実装
- JavaScript実装
- ロゴ正式制作
- Git操作
- GitHub操作
- 公開
- OGP制作
- favicon制作
- Markdown仕様書の全面更新

素材制作チャットは、
**正式ビジュアル素材制作に集中する。**

# 40. 制作思想

yoriのビジュアルは、

**「正解を教えてくれるファッションサービス」**

ではなく、

**「自分の感覚と暮らしを整理し、自分で選べるようになるサービス」**

であることを常に表現する。

華やかさ・トレンド感・AI生成としての美しさを優先して、
この考え方を壊さないこと。

最も重要なブランドメッセージは、

# 私に似合うを、私が選べるように。

である。
