28〜35歳前後の働く女性向けの、

単純に似合う服を選ぶのではなく、

---

# 4. ターゲット

## メインターゲット

**28〜35歳前後の働く女性**

仕事と私生活がある程度落ち着いてきた一方、
20代前半までの感覚で選んでいた服が少しずつしっくりこなくなっている。

ファッションには関心があるが、情報が多すぎて自分なりの判断軸を持てていない。

## 表面的な悩み

- 服はあるのに着たい服がない
- 朝、何を着るか迷う
- 買ったのに着ない服が増えている
- SNSで見た服が自分に似合うか分からない
- 仕事服が無難になりすぎる
- 休日服との切り替えが難しい
- 昔似合っていた服がしっくりこない
- 骨格診断やパーソナルカラーを服選びへ落とし込めない

## 深層課題

**「自分に似合う・自分らしい」を判断する軸が整理されていない。**

## 求める変化

- 朝の服選びに迷いにくくなる
- 買って後悔しにくくなる
- 自信を持って服を選べる
- 無理に流行を追わない
- 仕事でも休日でも自分らしくいられる
- 年齢を重ねても服を楽しめる

# 7. MY STYLE NOTE

初回体験後に利用者へ渡すフィードバック。

1. **MY BASE** — 取り入れやすい基本スタイル
2. **SILHOUETTE** — 選びやすいシルエット
3. **COLOR** — 手持ち服と合わせやすい色の考え方
4. **MY RULE** — 服を買う前に確認したいポイント
5. **NEXT ITEM** — 次に買い足すなら候補になるもの

禁止リストではなく、
**選択肢を狭めるのではなく、選びやすくする**ための資料とする。

**Quiet Editorial Lifestyle**

- 知的

- 自然体

## Hair

- 黒〜ダークブラウン
- 肩〜セミロング
- 自然なストレート〜緩い動き

## Makeup

- Natural
- 肌感を残す
- 強いメイクなし

## Wardrobe

**Simple + Contemporary**

- 白シャツ
- 柔らかなブラウス
- 薄手ニット
- テーラードジャケット
- ワイド / ストレートパンツ
- デニム
- ミディ〜ロングスカート
- シンプルなワンピース
- カーディガン

## Photography

- 柔らかな自然光
- 午前9時〜午後2時程度
- Side Light
- Neutral〜Slight Warm
- Low〜Medium Saturation
- 強いコントラストなし
- 過度な白飛びなし
- 過剰レタッチなし

残す：

- 自然な服のシワ
- 髪の少しの動き
